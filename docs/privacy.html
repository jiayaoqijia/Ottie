Privacy Policy

Last updated: March 2026

1. Overview

Ottie is open-source software that you can self-host. This Privacy Policy applies to the ottie.xyz website and the hosted one-click launch service at claw.altllm.ai. If you self-host Ottie, your privacy is governed by your own infrastructure — we have no access to your data.

2. Data We Collect

Website (ottie.xyz)

  • Analytics — we use Google Analytics to understand aggregate traffic patterns (page views, referral sources, device types). No personal data is collected beyond what Google Analytics provides by default
  • Cookies — Google Analytics sets cookies to distinguish unique visitors. You can opt out via your browser settings or the Google Analytics Opt-out Browser Add-on
  • Server logs — GitHub Pages may collect standard server logs (IP address, browser type, pages visited) as part of their service

One-Click Launch Service (claw.altllm.ai)

  • API keys — keys you provide are used solely to configure your Ottie instance and are not stored after your session ends
  • Session data — temporary session state required to run the service, deleted when the session ends
  • No conversation logging — we do not log, store, or read your conversations with the agent

Self-Hosted Instances

When you self-host Ottie, all data stays on your infrastructure. We have zero access to your conversations, API keys, wallet addresses, or any other data.

3. Data We Do NOT Collect

  • Wallet private keys or seed phrases
  • Conversation content or prompts
  • Transaction details or blockchain activity
  • Financial data or portfolio information
  • Personal identification documents

5. Third-Party Services

Ottie integrates with third-party APIs. When you use these integrations, your requests go directly to those services. Each has its own privacy policy:

  • GitHub Pages — website hosting
  • CoinGecko — market data
  • DefiLlama — DeFi data
  • Lido — staking data
  • Uniswap — swap data
  • Venice AI — private LLM inference (zero retention)
  • LLM providers (OpenAI, Anthropic, etc.) — per your own API key and their policies

6. Data Security

  • ClawWall DLP — prevents sensitive data (private keys, mnemonics) from reaching LLM providers
  • Domain constraint — the agent cannot access email, files, or browser — only blockchain operations
  • Prompt injection guard — protects against prompt injection attacks
  • HTTPS — all website and API traffic is encrypted via TLS

7. Your Rights

Since we collect minimal data:

  • Self-hosted users: You control all your data. Delete it anytime.
  • Website visitors: We don't collect personal data beyond standard server logs (controlled by GitHub).
  • One-click launch users: Session data is ephemeral and automatically deleted.

For any privacy questions, open an issue at github.com/jiayaoqijia/ottie/issues.

8. Children's Privacy

Ottie is not intended for users under 13. We do not knowingly collect data from children.

9. International Users

The ottie.xyz website is hosted via GitHub Pages (US-based). By using the site, you consent to data processing in the United States. For self-hosted instances, data stays in your chosen jurisdiction.

10. Changes

We may update this policy. Changes will be posted on this page with an updated date. The open-source nature of Ottie means you can always audit exactly what data the software handles.
