Review body preserved verbatim from codex output — see full file for
per-subsystem happy/unhappy/corner/edge matrix. Key findings CC R9
missed:

1. **Close TOCTOU race** — after `close(l.closed)`, a concurrent Prepare
   can still have both "send op" and "closed" cases ready in the select,
   and the select can pick the send, contradicting the "new calls after
   Close begins return an error" contract. Fix: gate enqueue with an
   atomic/mutex state BEFORE the select. Add concurrent Close+producer
   regression test.

2. **RecoverOrphans returns nil on empty DB** — `var out []OrphanedIntent`
   leaves nil. A JSON encoder renders `null` instead of `[]`. Fix:
   `out := make([]OrphanedIntent, 0)`.

3. **Same-millisecond ordering non-deterministic** — two Prepare calls in
   the same millisecond tie on `prepared_at` and come back in arbitrary
   order. Fix: `ORDER BY i.prepared_at ASC, i.rowid ASC` for a stable
   tiebreaker.

4. **Substring-matched SQLite error classification is brittle** — modernc
   exposes a typed `sqlite.Error` with `Code()`, so `wrapFinalizationError`
   should use `errors.As` + typed code match (SQLITE_CONSTRAINT_UNIQUE,
   SQLITE_CONSTRAINT_FOREIGNKEY) and fall back to substring only if the
   typed match misses.

5. **DBPath not URL-escaped in DSN** — `buildDSN` concatenates raw
   `DBPath` into a `file:` URI, so paths containing `?`, `#`, `&` can be
   misparsed. Use `url.URL{Scheme, Path, RawQuery}.String()`.

Missing regression tests:
- Concurrent Close vs producers (race).
- Non-nil empty orphan slice assertion.
- Deterministic same-timestamp recovery ordering.
- Direct abort-row payload readback (error_message persisted correctly).
- PRAGMA state assertion (confirm WAL is actually applied).
- Crash-without-Close durability test (documented gap).

Follow-ups (not blockers):
- Schema version table for future migrations.
- Bounded external_ids JSON payload size.
- Principal label validation once pkg/principal is wired in.
